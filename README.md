# Sonu Kumar | Frontend Developer Portfolio

A modern, responsive and interactive personal portfolio website built to showcase my frontend development skills, projects and web design work.

## 🌐 Live Demo

## ✨ Features

* Responsive design for mobile, tablet and desktop
* Modern dark/light mode toggle
* Smooth scrolling navigation
* Animated scroll reveal effects
* Interactive project filtering
* Responsive project cards
* Contact form with validation
* Bootstrap toast notifications
* Back-to-top button
* Social media links
* Glassmorphism-style UI
* Modern animations and hover effects

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Bootstrap Icons
* Google Fonts
